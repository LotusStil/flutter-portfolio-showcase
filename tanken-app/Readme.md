# Tanken App - Nearby Fuel & Charging Finder

Simple and fast Flutter app to find fuel stations and EV charging nearby.

### What it does
- Finds stations within ~10 km radius
- Shows stations on OpenStreetMap + bottom sliding list
- For fuel: shows prices (Diesel, Benzin, E10)
- For EV: shows plug types (CCS, Type2, CHAdeMO)
- On tap -> Opens Google Maps for navigation

### Tech Stack
- Flutter / Dart
- OpenStreetMap (flutter_map)
- Tankerkoenig API / OpenChargeMap API
- Google Maps intent

### Key Feature for Clients
Clean API integration + Map + List sync. Perfect example for "Geräteübergreifende Kompatibilität".
